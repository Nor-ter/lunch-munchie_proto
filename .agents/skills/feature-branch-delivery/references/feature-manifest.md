# Feature manifest

Use in the PR description or task record.

```md
## Feature
- Outcome:
- Non-goals:
- Source / target:

## Acceptance criteria
- [ ]

## Scope
- UI:
- API / types:
- D1 schema or migrations:
- Cloudflare/deployment:
- Protected existing behavior:

## Validation and delivery
- Focused tests:
- Full quality gate:
- Manual verification:
- Migration order / rollback:
- PR / merge / deployed environment:
```

Split expanded scope into a new feature branch instead of silently enlarging a PR.
