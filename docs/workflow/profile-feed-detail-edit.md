# Profile feed detail and edit flow

## 목적

프로필의 작은 관리 목록과 실제 피드 경험을 분리한다. 카드 본문을 누르면 메인 피드와 동일한 큰 카드 상세를 열고, 명시적인 `수정` 액션에서만 단계형 편집을 시작한다.

## 라우팅 계약

- 프로필 피드 상세: `/feed/:feedId?from=profile`
- 프로필 피드 수정: `/feed/:feedId/edit?from=profile`
- 수정 완료 후 기존 피드 ID의 상세 페이지로 돌아간다.
- 상세의 뒤로 가기는 `from=profile`이면 프로필, 그 외에는 Munchie Feed로 복귀한다.

## 편집 단계

1. `코스 선택`: 연결된 기존 코스를 확인하거나 다른 코스로 변경한다.
2. `사진·한줄평 수정`: 선택 코스의 사진 후보와 직접 업로드 사진에서 순서를 선택하고 한줄평을 수정한다.
3. `수정 미리보기`: 실제 `FeedPostCard`로 결과를 확인한 후 `수정 완료`로 저장한다.

코스를 변경하면 이전 코스 사진은 자동으로 해제해 코스와 무관한 사진이 실수로 남지 않게 한다. 원래 코스를 다시 선택하면 기존 사진을 복원한다.

## 권한과 데이터 계약

- `isMyPost(post)`가 참인 피드만 수정 페이지에 접근할 수 있다.
- `updateFeedPost`는 `courseId`, `photos`, `caption`, `tags`를 함께 갱신한다.
- 좋아요, 저장 수, 댓글, 작성일, 피드 ID는 수정해도 유지한다.
- 미리보기 단계에서는 실제 상태를 변경하지 않는다.

## 검증 루프

1. 프로필의 내 피드 카드 본문을 눌러 큰 피드 상세로 이동한다.
2. 상세의 수정 버튼과 프로필 복귀 버튼을 확인한다.
3. 편집에서 코스를 변경하고 새 코스 사진 후보가 표시되는지 확인한다.
4. 사진과 한줄평을 변경해 미리보기 카드에 반영되는지 확인한다.
5. `수정 완료` 후 동일한 피드 ID의 상세에 변경 내용이 보이는지 확인한다.
6. 좋아요·댓글·작성일이 유지되는지 확인한다.
7. 다른 사용자의 피드 수정 URL에 접근하면 권한 차단 화면이 표시되는지 확인한다.
