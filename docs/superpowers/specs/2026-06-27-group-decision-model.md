# 그룹 결정 모델 — 하이브리드 (least-misery로 좁히고 → 투표)

- 날짜: 2026-06-27
- 상태: **목적함수 확정 · B~F 제안(검토 중) · 코드는 잠정 baseline**
- 배경: 그룹 결정의 정합성 논의 — "여러 명이 결승 다시를 하면 하나로 수렴 안 되는 문제"에서 출발.
- 관련: [결정 메커니즘 PDF](../../engine/lunchie_decision_mechanics.pdf) (솔로 '둘 다 별로' & 재진입), `server/engine/group.ts`.

## 0. 왜 이 문서

목적함수(무엇을 최적화하나)를 안 정한 채 단계마다 다른 기준(슬레이트=least-misery,
예선 랭크=싫어요, 결승=다수결)이 섞여 있었다. 먼저 목적을 정하고, 거기서 B~F를 도출한다.
**코드보다 이 모델이 먼저다.** 현재 코드는 이 모델의 일부만 구현한 잠정 baseline.

## A. 목적함수 — 확정: **하이브리드**

> least-misery로 "아무도 크게 싫어하지 않는" 안전한 top-2로 좁힌 뒤, 그 둘 중엔 **다수결**.

- 최소 후회(거부권)와 최대 만족(다수결)의 절충.
- least-misery는 **안전 필터**(누가 미워하는 곳 제거), 투표는 **인간의 최종 선택**.
- 솔로는 개인 듀얼(2AFC), 그룹은 이 합의 모델. 둘은 분리.

## 확정 모델 (하이브리드 v1)

```
예선(PRELIM)  각자 LIKE/DISLIKE
   └ 완료 = 전원 OR 호스트 '지금 진행' OR 마감
        ↓
후보 선정     least-misery 랭크에서 top-2 (좋아요≥1 · 과반에게 미움받지 않은 곳)
   ├ 후보 <2 → top-1 확정 (결승 생략)
   └ 후보 2  → 결승(FINAL)
        ↓
결승(FINAL)   3지선다: A / B / 둘 다 별로   (1인 1표)
   └ 완료 = 전원 투표 OR 호스트 OR 마감
        ↓
확정(DONE)
   ├ '둘 다 별로' 단독 최다 → reroll: 다음 least-misery 2곳으로 새 결승
   │                          (소진 시 새 슬레이트, 그래도 없으면 1위 폴백 = 무한루프 방지)
   └ 그 외 → 표 많은 곳. 동률 → 예선 상위(least-misery top)
```

## B~F 결정

### B. 결승 트리거
- 후보 2곳이면 결승을 연다(투표가 하이브리드의 핵심).
- "후보" 자격 = 좋아요 ≥ 1 **그리고** 과반에게 미움받지 않음(들러리 배제: 소수만 찍은 곳은 결승 진출 X).
- 후보 < 2 → 결승 생략, top-1 확정.

### C. 그룹 탈출구 ★ (원래 문제의 답 · **확정 대기**)
- 결승을 **A / B / "둘 다 별로"** 3지선다로.
- "둘 다 별로"가 **단독 최다** → **reroll**(다음 2곳). per-person이 아니라 **그룹 다수결**이라 수렴 유지.
- 솔로의 "둘 다 별로"를 그룹 스케일로 옮긴 것.

### D. 정족수 · 노쇼
- 예선/결승 완료 = `전원 OR 호스트 '지금 진행' OR 마감`. 노쇼가 타이머까지 전체를 잡지 않게 호스트 강제 진행.
- 마감 시 던진 표로 결정. 0표면 least-misery 1위.
- (호스트 버튼은 UI 후속 — 로직은 "강제 진행 트리거"만 필요.)

### E. 동률 · 마감
- 결승 표 동률 → 예선 상위(least-misery top).
- "둘 다 별로"는 **단독 최다일 때만** reroll(동률이면 결정 쪽 = 무한 reroll 방지).
- 예선 동률 → 좋아요 수 → 엔진 순위로 **결정적** 정렬.

### F. 일관성
슬레이트 · 예선 랭크 · 후보 선정 모두 least-misery(안전 필터), 결승만 투표, "둘 다 별로"가 안전밸브.
한 방향으로 일관.
